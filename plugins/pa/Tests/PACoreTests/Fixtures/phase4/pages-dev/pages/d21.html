Pebblecal 3.8

Released 19 June

New

  • Travel time: an event with a place can show the time to get there, by car or by public transport. Turn it on in Settings, Events.
  • Week numbers in the month view.
  • Import of .ics files with more than 10,000 events.

Changed

  • The default reminder for all-day events is now 9:00 on the day, not midnight.
  • Pebblecal needs macOS 13 or later.

Fixed

  • A repeating event moved by one hour after a change of daylight saving time.
  • Search did not find events with an accent in the title.
  • The app used too much memory with many shared calendars.

Before you upgrade, export a backup in File, Export. Version 3.8 changes the database, and an older version cannot open it.
