4 Back up a database

Tallyfold Server stores each ledger as one database file. A backup copies the file while the server runs, so users can keep working. Make a backup before each upgrade and at least once a day.

4.1 Full backup

Run the backup command as the user that owns the server. The command writes a compressed copy to the folder that you name.

tallyfold backup --ledger main --to /srv/backups --keep 14

The option --keep removes old copies of the same ledger and keeps the newest 14. Without --keep, the command keeps every copy, and the disk can fill up.

A backup of a ledger of 2 GB takes about 40 seconds on a normal server. During the backup, writes are slower, but no write is lost.

4.2 Restore

To restore, stop the server first. A restore replaces the ledger file, and the server must not write to it at the same time.

tallyfold stop
tallyfold restore --ledger main --from /srv/backups/main-2024-05-02.tfz
tallyfold start

After a restore, all entries made after the time of the backup are gone. Tell your users before you restore.
