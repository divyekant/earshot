earshot is a voice interface for macOS. It finds the app, focuses the text box, types what you dictate and clicks what you name. Speech and decisions stay on your Mac.

Things you can say

  • Slack Ravi, running lateOpens Slack, opens the conversation with Ravi, focuses the message box and types “running late”.
  • WhatsApp MomOpens the chat with Mom and focuses the message box. Then you dictate.
  • Open hn.comOpens the web address in your browser.
  • Click SendClicks the button with the label “Send” in the front window.
  • Show numbersPuts a number on each item that you can click. Then say “click 4”.
  • TypeTypes your next sentence into the text field that has the focus.

earshot has no script for each app. It reads the menus, sidebars and search results of your apps through macOS accessibility. You approve the apps that it can act in.

How a command runs

  1. Hear

    Apple speech, or NVIDIA Parakeet if you give earshot the model file, turns your voice into text on the Mac.

  2. Decide

    Small rules find the app, the target and the action in about 300 ms. No large AI agent runs in this step.

  3. Act

    earshot uses macOS accessibility to open, focus, type or click. Then it shows a short note with the result.

Hold key

Hold the right Option key, speak, release. You can pick another key.

Always on

Off until you turn it on. earshot waits for a wake phrase, such as “hey jarvis”. Teach it your voice with five phrases, and other voices cannot start a command.

No audio leaves your Mac.

earshot saves no audio. Speech recognition and every decision run on the Mac by default.

One optional cloud helper, Jev, can answer when the rules are not sure. It is off by default. If you turn it on, earshot sends text only: the command words and a short list of labels on the screen.

The Jev key stays in the macOS Keychain. Your settings, app list and name list are JSON files in ~/Library/Application Support/earshot.

It never presses Send unless you say “send”.

Warning: a Return key press in a message box sends the message. You cannot undo a sent message.

  • No Return or Send in a message box without the word “send”.
  • No action on sign-in, code or payment pages.
  • No typing into a password field.
  • Action only in the apps that you approve.

Build it

earshot is early software. There is no signed download yet, so you build it from the source.

  • A Mac with Apple silicon or an Intel processor
  • macOS 14 or later. macOS 26 has the best speech engine.
  • Xcode 16 or later, or the Command Line Tools with Swift 6
# get the source
git clone https://github.com/divyekant/earshot.git
cd earshot/app

# test, then build the app bundle
swift test
scripts/build-app.sh
open build/Earshot.app

Then click the earshot icon in the menu bar, open Manage…, give the permissions and approve your apps. The README has each step.
