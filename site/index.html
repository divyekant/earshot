Say it.
Your Mac does it.

earshot is a local voice interface for macOS. Look at the screen and say what you want. earshot finds the app, focuses the text box, types what you dictate and clicks what you name.

All audio stays on your Mac. Small, fast rules make each decision. earshot does not use a large AI agent for each step.

What you can say

"Slack Ravi, running late"Opens Slack, opens the conversation with Ravi, focuses the message box and types "running late".
"WhatsApp Mom"Opens WhatsApp, opens the chat with Mom and focuses the message box. You then dictate.
"Open hn.com"Opens the web address in your browser.
"Click Send"Clicks the button with the label "Send" in the front window.
"Show numbers", then "click 4"Shows numbers on the items that you can click, then clicks item 4.
"Type", then your sentenceTypes the next sentence into the text field that has the focus.

How it works

Three steps run on your Mac for each command.

  1. 1

    Hear

    Speech becomes text on your Mac. earshot uses Apple speech, or NVIDIA Parakeet if you give it the model file. earshot saves no audio.

  2. 2

    Decide

    Small, fast rules find the app, the target and the action. The rules have a time limit of about 300 ms. There is no large-model agent loop in the command path.

  3. 3

    Act

    earshot reads the menus, sidebars and search results of your apps through macOS accessibility. Then it focuses, types or clicks.

App support is data, not code

earshot has no script for each app. It discovers your apps and reads their labels. You approve the apps that earshot can act in.

Hold key

Hold the right Option key, say a command, then release the key. earshot shows a small note with the result. You can change the key.

Always on off by default

earshot listens for a wake phrase, for example "hey jarvis". Say it 5 times to teach earshot your voice. Then other voices cannot start a command.

Privacy

  • Audio stays on your Mac

    earshot sends no audio to the cloud and saves no audio on disk.

  • Decisions stay on your Mac

    By default, the rules decide each command on your Mac with no network.

  • Optional cloud help is off

    One optional cloud model, Jev, can help when the rules are not sure. It is off by default. If you turn it on, earshot sends only text: the command words and a short list of labels on screen.

earshot keeps the Jev key in the macOS Keychain. Settings, the app list and the name list are JSON files in ~/Library/Application Support/earshot.

Safety

Warning: a Return key press in a message box sends the message. You cannot undo a sent message.

  • earshot never presses Return or Send in a message box unless you say "send".
  • earshot does not act on sign-in, code or payment pages.
  • earshot acts only in the apps that you approve.
  • earshot never types into a password field.

Get started

earshot is early software. There is no signed download yet. Build it from the source.

You need

  • A Mac with Apple silicon or an Intel processor.
  • macOS 14 or later. macOS 26 gives the best speech engine.
  • Xcode 16 or later, or the Command Line Tools with Swift 6.
# Get the source
git clone https://github.com/divyekant/earshot.git
cd earshot/app

# Run the tests
swift test

# Build the app bundle
scripts/build-app.sh
open build/Earshot.app

Then open Manage… from the menu bar icon, give the permissions and approve your apps. The README gives each step.
