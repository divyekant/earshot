Talk to any app on your Mac.

Say what you want. earshot opens the chat, clicks the link, picks the menu item or types your words. It acts in under a second, and nothing you say leaves the Mac.

Get the source Why it is different

Not a voice assistant. A faster hand.

Voice assistants answer questions. Dictation types words. earshot does the clicks and keystrokes between them, in the apps you already use.

  1. No AI model to wait for

    Small rules on your Mac decide each command in about 20 ms. There is no AI model to wait for. A spoken web click lands 70 to 90 ms after you stop talking.

  2. Works in apps it has never seen

    earshot reads the buttons, links, menus and sidebars of the front app through macOS accessibility. There is no plugin and no script for each app. If you can see the label, you can say it.

  3. Every menu item is a voice command

    Say “select all”, “export as PDF” or “new window” in any app. earshot finds the item in the app’s own menus and presses it.

  4. The web by name

    “Open the second result.” “Click Pull requests.” “Search for train times.” earshot reads the page in Chrome and acts on the link you name.

  5. Your words in any text box

    Hold the key and talk. Plain words go into the field that has the focus: a mail, a doc, a search box. Pause to think; earshot waits.

  6. Only your voice, only your phrase

    In always-on mode, earshot wakes on a phrase that you pick, in any language. It checks that the voice is yours, so the TV and other people cannot start a command.

What to say

Short, plain commands. Each clip shows earshot doing one of them.

Message anyone, in any chat app

  • Slack Ravi, running lateOpens the chat with Ravi and types the message. It does not send.
  • WhatsApp MomOpens the chat and puts the cursor in the box. Then you talk.
  • iMessage Sam, landed safelyThe same command works in Messages.
  • SendSends what earshot just typed, only because you said it.

Use the web without the mouse

  • Open hn.comOpens the address in your browser.
  • Search for trains to LisbonTypes into the search field of the page.
  • Open the second resultClicks the result by its position.
  • Click Pull requestsClicks the link by its label, even if you say it a little wrong.

Say any menu item, in any app

  • Select allFinds Select All in the Edit menu and presses it.
  • Export as PDFWorks for the items in the app’s own menus.
  • Open ZoomOpens or brings up any app that you approved.

Click things that have no name

  • Show numbersPuts a number on each item that you can click.
  • Click 7Clicks item 7.
  • Click ShareOr name the button, if it has a label.

Write by talking

  • Hi Sam, the deck is readyHold the key and talk. Plain words go into the text field that has the focus.
  • TypeThen say a long sentence, with pauses. earshot waits and types all of it, also in always-on mode.

The router results with no miss use the optional cloud helper, Jev, for the commands that the rules were not sure of. With the rules alone, on the Mac: 40 of 42 chats and 42 of 45 web clicks.

No audio leaves your Mac.

earshot saves no audio. Speech recognition and every decision run on the Mac by default.

One optional cloud helper, Jev, can answer when the rules are not sure. It is off by default. If you turn it on, earshot sends text only: the command words and a short list of labels on the screen.

The code is open source under the MIT License. Read it, build it and change it. Your settings, app list and name list are JSON files in ~/Library/Application Support/earshot.

It never presses Send unless you say “send”.

Warning: a Return key press in a message box sends the message. You cannot undo a sent message.

  • No Return or Send in a message box without the word “send”.
  • No action on sign-in, code or payment pages.
  • No typing into a password field.
  • Action only in the apps that you approve.

Build it

earshot is early software. There is no signed download yet, so you build it from the source.

  • A Mac with Apple silicon or an Intel processor
  • macOS 14 or later. macOS 26 has the best speech engine.
  • Xcode 16 or later, or the Command Line Tools with Swift 6
# get the source
git clone https://github.com/divyekant/earshot.git
cd earshot/app

# test, then build the app bundle
swift test
scripts/build-app.sh
open build/Earshot.app

Then click the earshot icon in the menu bar, open Manage…, give the permissions and approve your apps. The README has each step.
